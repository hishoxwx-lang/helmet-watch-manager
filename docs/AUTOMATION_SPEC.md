# 在庫通知くん 改良スペック（2026-08-14）

## 概要

既存のPOIZON出品管理＋在庫監視システム（helmet-watch-manager）に7つの改良を加える。

## 改良項目

### A. 出品一覧の自動取得＋自動更新

**現状**: ページを開いても手動で「取得」ボタンを押す必要がある。

**仕様**:
- ページ表示時（DOMContentLoaded）に自動で`loadListings()`を呼ぶ
- 60秒ごとに自動リフレッシュ（`setInterval`）
- 自動リフレッシュ中はヘッダーにスピナー表示（ボタンは無効化しない）
- 手動取得ボタンも維持
- 自動リフレッシュはエラーでも静かにリトライ（アラートを出さない）

### B. テーブル列ソート機能

**現状**: 75件以上の出品がデフォルト順（API返却順）で表示されるのみ。

**仕様**:
- 列ヘッダークリックでソート: 商品名・SKU・品番・価格・カート価格・市場最低値・仕入先在庫
- クリックごとに 昇順→降順→解除 の3状態トグル
- ソート中は列ヘッダーに ▲▼ インジケータ表示
- ブランドタブ・検索フィルタと組み合わせ可能（フィルタ適用後にソート）
- ソート状態はメモリ保持（ページリロードでリセット）

### C. 在庫変化履歴タイムライン

**現状**: state.jsonに最新状態のみ保存。過去の変化が消える。

**仕様**:
- checker.pyが状態変化時に`state_history.json`に追記
- 形式: `[{"product_id": 1, "name": "...", "prev_state": "IN_STOCK", "new_state": "SOLD_OUT", "detail": "...", "timestamp": "2026-08-14 12:00:00"}]`
- 最新1000件まで保持（超過時は古いものから削除）
- POIZON画面の各行に「📋 履歴」ボタンを追加 → クリックでモーダル表示
- 新規APIエンドポイント: `GET /api/history/<product_id>` で履歴JSONを返す
- 新規APIエンドポイント: `GET /api/history` で全履歴JSONを返す（最新50件）

### D. 一括価格操作

**現状**: 1件ずつクリックしてインライン編集するしかない。

**仕様**:
- 各行にチェックボックスを追加（左端）
- ヘッダーに「一括操作」ツールバー: [選択中: N件] [市場最低値に調整] [選択解除]
- 「市場最低値に調整」: 選択した出品のうち、自分の価格 > 市場最低値 のものを市場最低値に変更
- 確認ダイアログで変更内容一覧を表示してから実行
- 実行中はプログレスバー表示（N/M件完了）
- API: 既存の`/api/poizon/update_price`を1件ずつ順次呼ぶ（レート制限対策で1秒間隔）

### E. ページネーション（100件超対応）

**現状**: `page_size=100`で固定。100件超えると残りが取得できない。

**仕様**:
- `poizon_api.py`の`query_listings()`で`exclusiveStartOffsetId`を使ったページングループ
- `get_active_listings()`内で全件取得までループ（1ページ100件→次ページ→…）
- 各ページ間に500msのスリープ（API負荷軽減）
- UIには「N件中 M件表示」を表示（全件取得済みなので実質全件表示）
- フッター件数表示のみ（ページ分けUIは不要、全件一覧表示）

### F. Discord通知テスト送信

**現状**: 設定画面からWebhookのテスト通知が送れない。

**仕様**:
- 設定画面（settings.html）のDiscord Webhook URL欄の横に「テスト送信」ボタン追加
- 新規APIエンドポイント: `POST /api/test_discord` → 保存中のWebhook URLにテストメッセージ送信
- 送信内容: 「🔔 テスト通知: 在庫通知くんのDiscord通知設定は正常に動作しています。」
- 結果をアラートで表示（成功/失敗 + HTTPステータスコード）

### G. /runの非同期化

**現状**: `/run`が同期的にchecker.pyをsubprocess呼び出し（最大120秒UIが固まる）。

**仕様**:
- `/run`をバックグラウンド実行に変更: subprocess.Popenで起動→即座にレスポンス返す
- 実行状態を`/api/check_status`で取得可能に（running/done/idle + 最終実行時刻）
- POIZON画面の「▶ 今すぐチェック」ボタン → クリックで「チェック実行中...」表示 → ポーリング完了確認 → リスト自動再読み込み
- チェック完了時はDiscord通知と同じタイミングでUIに通知（2秒後に自動消去）

## 技術制約

- 言語: Python 3.x（Flask）+ Vanilla JS（追加フレームワークなし）
- デプロイ: ConoHa Windows Server、GitHub push → Web UIの「最新版に更新」で反映
- 既存データ（products.json, config.json, state.json, poizon_links.json）は破壊しない
- 新規ファイル: `state_history.json`（自動生成）
- 既存の`/update`ルートのtargetsリストに新しいテンプレートがあれば追加（今回は既存テンプレートのみ更新）

## 受入基準

1. ページを開くと出品一覧が自動表示される。60秒後に自動更新される
2. 列ヘッダークリックでソート可能（昇順/降順/解除）
3. 在庫状態が変化すると履歴に記録され、UIから確認できる
4. 複数選択 → 「市場最低値に一括調整」が動作する
5. 100件超の出品が全件取得・表示される
6. 設定画面からDiscordテスト通知が送れる
7. チェック実行ボタンを押してもUIが固まらない
